## 5. 发布检查清单（M6 逐条执行）

1. 名字占用核对**在建仓之前**：`gh api -X GET search/repositories -f q='depcheck-live in:name' --jq .total_count`
   （**`-X GET` 不能省**；0 必须来自成功响应，不是限流假 0），并把"核过、未占用、无映射"写进留档。
2. `node tools/check-desensitized.mjs` 0 命中。
3. 干净环境：`git clone` 到中立目录 → `npm test` → `node bin/depcheck-live.mjs --version` → `check` 样例。
4. `node tools/check-release.mjs --pre-tag` 全绿。
5. tag → Release（附产物）→ `gh release download` 回取验 sha256。
6. tag 后在 `git archive <tag>` 解出树里重跑三道门。
