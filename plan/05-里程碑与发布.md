### M3 DoD（判定层 —— 已完成）

- [x] 五判定态 + `VERSION-BEHAVIOR-DRIFT` 实现
      —— 五判定态由 M2 落地并本棒收口核对（`evidence.rule` 节号仍准确）；
      `VERSION-BEHAVIOR-DRIFT` 本棒落位（`src/drift.mjs`），判据 = **符号行为**、单位 = **引用点**
      （`data/README.md` §5.5）。M3 落位时修了两处真缺陷：
      ① `drift` 原按包比整份 `exports` 指纹 → 实测 date-fns 3.6.0→4.4.0 零移除，是系统性假阳性；
      ② 同一引用点被 MISSING-EXPORT 与 DRIFT 双重计数 → `problems` 算两遍。
- [x] `bench` 全绿，含 chalk vs zod/glob 同代码不同包对照组
      —— `node bin/depcheck-live.mjs bench` 实测 **6 语料 / 28 引用点 / 28 通过 0 失败**；
      C3 的"1 红 4 绿"由 `tests/bench.test.mjs` 单独钉住（1 条 MISMATCH + 4 条 RESOLVED）。
- [x] `drift` 无基线时记 `NO-BASELINE`，不猜
      —— 实测：只有 `NO-BASELINE` 时退出码 **3**（`data/README.md` §5.1 的"基准缺失"）；
      `NO-BASELINE` 不进 `problems`，进 `gaps`（`tests/drift.test.mjs` 12 条 + C6 逐点对账）。
      ⚠️ **本项曾在 M3 首次收尾时是假门**：`expected.json` 里的
      `exitCodeWhenOnlyNoBaseline` / `exitCodeWhenDrift` / `problemsCountsDrift` /
      `noBaselineCountsProblems` / `noBaselineGoesTo` 五个**真值字段无任何断言**——
      声明了却没人验，改实现后它们可以悄悄失配而全绿。M3 复审已补 3 条断言
      （真值一律从 `expected.json` 读，不硬编码），并用两次变异验证确认会变红。
      **另修**：`check --with-drift` 的两处测试原先没传 `--baseline-dir`，
      靠 `cwd` 的隐式解析碰巧跑通——换个 `cwd` 就静默退化成"没读基线"，已改为显式传参。
- [x] C6 的 `src/` + 逐点 `evidence` 补齐
      —— 载体经实测从 date-fns 改为 **zod 3.25.76→4.6.7**（该包实测移除 31 个符号）；
      date-fns 保留在"无基线"一侧。改动理由是**真值本身错了**，不是改真值凑实现。
- [x] `data/fingerprints/` 落位（历史基线由真实 tarball 生成，未伪造）
